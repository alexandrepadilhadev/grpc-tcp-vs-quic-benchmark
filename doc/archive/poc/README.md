# POC (histórico)

Primeira fase do TCC: uma única RPC (`BenchService.Unary`) entre um cliente e um servidor, em h2 e h3, que validou o transporte simétrico, a carga em taxa fixa, a injeção de falhas e a análise. O código está na tag `poc-v1` (`59e95eb`); estes documentos ficam aqui só como registro e **não descrevem o sistema atual**.
